# Changelog

All notable changes to **PhishGuard AI** will be documented in this file.

## [1.0.0] - 2026-07-22

### Added
- **Core Engine**: Implemented FastAPI asynchronous web routing for low latency email scans.
- **Machine Learning**: Built DistilBERT sequence classifier and Scikit-Learn Logistic Regression fallback interface.
- **Cyber Heuristics**: Programmed threat parser scanning domain typosquatting, Punycode spoofing, and url shorteners.
- **Interactive SPA Dashboard**: Crafted responsive cybersecurity dashboard layout utilizing Glassmorphism styles and Chart.js graphs.
- **Streamlit Demo**: Designed alternative portal wrapping endpoints with custom dark-red cyber styling.
- **Infrastructure**: Configured Docker and docker-compose files.
- **CI/CD**: Configured GitHub Actions integration validation pipeline.
