Common Phishing Indicators

PhishGuard AI scans for these core social engineering markers during mail analysis:

Urgent Language Requires immediate attention (e.g. "within 24 hours", "account freeze").
Credential Harvesting Requests passwords, PIN codes, security questions, or multi-factor tokens.
Fake Invoices Claims outstanding vendor balances or shipping fees (e.g. Quickbooks, FedEx).

URL Spoofing Typologies

Phishing emails rely heavily on technical tricks embedded inside links:

IDN Homograph Attacks Uses internationalized lookalike unicode characters to spoof valid domains (e.g. аpple.com using Cyrillic 'а').
URL Shorteners Hides final server redirections behind short links (e.g. bit.ly).
Typosquatting Common spelling replacements like micros0ft.com or paypal-security.net.
