# Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**DO NOT open public issues for security vulnerabilities.**

If you discover a security flaw or vulnerability (e.g. SQL injection, XSS leaks, model bypass patterns), please report it responsibly:

1. Email your findings privately to `security@phishguard-ai.net`.
2. Include steps to reproduce the issue, sample inputs, and potential mitigations.
3. We will acknowledge your email within 48 hours and coordinate a private fix within 30 days before public disclosure.
